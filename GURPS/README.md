# Character Sheet for the Generic Universal Roleplaying System (GURPS), 4th Edition

## To the Future Authors - from Mike W (02/25/2026)
I need to mention that the original author(s) misspelled the words Miscellaneous (as Miscellwneous) and Encumbrance (as Encumberance) in both the CSS and HTML files. Rather than write extensive code to fix this, I corrected only the cosmetic portions. Also note that the original author(s) use the word Fear in place of Fright, although the proper word is Fright. As with the misspelled words, I changed no code other than the cosmetic side. This seemed simpler than spending hours writing code to transfer values from the attributes in question and ensure it still functions. It also avoids having to explain it to the users in case they used those misspelled attributes in homemade macros.
